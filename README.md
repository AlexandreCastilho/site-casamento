# 💍 Site de Casamento - Alexandre & Larissa

Site oficial e interativo do casamento de **Alexandre & Larissa**, desenvolvido com HTML5, CSS3 moderno e JavaScript puro.

---

## ✨ Funcionalidades

- **🕒 Contagem Regressiva:** Cronômetro em tempo real até o momento do "Sim".
- **💌 Confirmação de Presença (RSVP):** 
  - Autocomplete com validação a partir da lista oficial de convidados.
  - Modal inteligente para agendamento da van de segurança/transporte.
- **🎁 Lista de Presentes Interativa:**
  - Categorias e filtros de presentes.
  - Modal de contribuição com chave Pix (Copia e Cola e QR Code) e confirmação.
- **📸 Galeria de Fotos e Vídeos:**
  - Trilhos flutuantes com parallax suave no scroll em desktops.
  - Carrossel e visualizador modal de fotos e vídeos da chácara.
- **💬 Mural de Recados:** Espaço para mensagens carinhosas deixadas pelos convidados.
- **📍 Informações do Local e Horários:** Integração com mapas, cronograma e dicas para o grande dia.
- **📱 100% Responsivo:** Otimizado para smartphones, tablets e computadores.

## 🚀 Como Executar Localmente

Como o projeto é construído com tecnologias web padrão (Vanilla JS, HTML e CSS), não há necessidade de compilação ou instalação de dependências.

1. Clone o repositório ou faça o download dos arquivos:
   ```bash
   git clone https://github.com/SEU-USUARIO/site-casamento.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador web moderno:
   - Ou utilize a extensão **Live Server** do VS Code para uma experiência com auto-reload.

---

## 🌐 Publicação no GitHub Pages

Para publicar este site gratuitamente na internet usando o GitHub Pages:

1. Acesse o seu repositório no GitHub.
2. Vá em **Settings** (Configurações) > **Pages** (no menu lateral esquerdo).
3. Na seção **Build and deployment**:
   - **Source**: Selecione `Deploy from a branch`.
   - **Branch**: Selecione `main` e a pasta `/ (root)`.
4. Clique em **Save**.
5. Em poucos instantes, o GitHub fornecerá o link público do site (ex: `https://seu-usuario.github.io/site-casamento/`).
